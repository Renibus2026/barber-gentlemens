# The Gentlemen's Barbershop 💈

Премиальный лендинг для мужского барбершопа и закрытого клуба «The Gentlemen's Barbershop».

## Особенности проекта
- **Атмосферный дизайн Dark Heritage & Loft**: винтажная кирпичная кладка, благородное темное дерево, янтарно-золотые акценты (#D4AF37) и глубокие угольные тени.
- **Интерактивный Hero-блок**: нейросетевой силуэт брутального джентльмена с бесшовным растворением в фон и мягким темным ореолом.
- **Плавные анимации появления (Scroll Reveal)**: элементы элегантно поднимаются и проявляются по мере скролла страницы.
- **Интерактивный прайс-лист и конфигуратор услуг**: фильтрация по категориям (Стрижки, Борода, Комплексы, Королевский уход) с моментальным расчетом стоимости.
- **Интерактивная галерея интерьера и работ**: фильтры по категориям, модальное окно полноразмерного просмотра.
- **Отзывы с рейтингом 4.9**: карточки реальных гостей с Яндекс Карт и 2ГИС.
- **Быстрая онлайн-запись**: модальное окно выбора мастера, услуги и времени с валидацией и маской телефона.
- **100% адаптивность (Mobile-First)**: оптимизировано под смартфоны, планшеты и десктопные 4K-дисплеи.

## Стек технологий
- **HTML5** (семантическая верстка, Open Graph, микроразметка Schema.org)
- **CSS3** (Custom Properties, Flexbox, CSS Grid, Backdrop Filter, Masking & Blending)
- **Vanilla JavaScript** (модальные окна, калькулятор, слайдеры, плавный скролл, IntersectionObserver)
